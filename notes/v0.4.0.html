Features

  • Split view mode with configurable editor/preview positioning (`splitEditorOnLeft`)
  • `ViewMode` enum replacing `openInEditMode` — supports editor, preview, and split modes
  • Image proxying via `WKURLSchemeHandler` for correct rendering in preview
  • New themes: Nord, One Dark, Catppuccin Latte, Catppuccin Mocha

  • Toolbar and split pane width corrections
